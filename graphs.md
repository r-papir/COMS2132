
# Graphs

<ins>Defintions</ins>
+ **Graph:** a pair of two sets fo vertices and edges, **G = (V,E)**.
+ **Vertices:** the set of vertices or *nodes*
+ **Edges:** the set of edges; each edge is a pair **(v,w)**, where **v,w ∈ V**
